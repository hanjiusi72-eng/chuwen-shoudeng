# 光亮 · 龙虎灯 — 视频参考融合版

以用户提供的 `b.mov` 为流程与气氛参考，把粉色民俗交互和深色灯坊合为同一个网页。网页保留真实游戏操作，不使用录屏替代交互。

## 打开和下载

- 在线入口：仓库根目录 `index.html`。
- 观看与下载页：`download.html`，含在线入口、离线交互版和网页源码下载。
- 离线交互包：`showcase/downloads/game-offline-mac.zip`。解压后打开 `guangliang-offline.html`，不需要安装、终端或网络。Chrome / Edge / Safari 的真实 `file://` 使用仍需在目标设备验证；云端自动测试通过 HTTP 提供同一份单文件，并阻止其他网络请求。
- 成灯后可点击「保存我的灯」，下载包含自选纹样和自定义心愿的 1600×1200 PNG。

## 开发

零 npm 依赖；Phaser 与 Three.js 都随项目保存，不依赖 CDN、账号或 API Key。

```sh
cd /workspace/chuwen-shoudeng
python3 -m http.server 8686
```

也可在 macOS 双击 `start.command`。源码版通过 HTTP/HTTPS 打开，避免浏览器对文件协议的贴图限制。每项云任务使用已有隔离 checkout，无需额外 Git worktree。

## 主线与衔接

四段粉色纹样序言 → 山村序章 → 掷骰采药 → 治虎 / 医龙 → 龙虎赠灯 → 药庐济世 → 木匠传艺 → 扎灯 → 千灯初上 → 守灯夜战 → 天明 → 灯坊绘纹 → 题写心愿 → 点亮与保存。

- 主线按参考视频从赠灯进入制药，不插入市集关卡；市集及原版画灯等旧交互保留在源码中。
- 制灯页沿用参考片的粉色几何底纹、站姿木匠、悬空灯体与材料托盘。
- 场景及剧情镜头保留上一画面，叠化显露下一画面；不再每次淡出到黑屏。
- 开场、游戏与灯坊共用一个 Web Audio 上下文、一条持续前进的小节时钟。配器在整小节边界交叉渐变；夜间低回，天明和灯坊转为柔和的日夜混合层，不重新播放曲头。不把参考片拼接的音轨带入网页。
- 灯坊为实时三维纸灯模型：拖动或左右方向键旋转，选择龙虎纹样，或切换画笔在模型表面自由绘画；输入最多八字心愿，点亮并保存图片。WebGL 不可用时退为平面纸灯，保留绘画、题字、点亮与保存。
- 「重访篇章」支持分章体验；序言页「直接去灯坊」方便快速查看新结尾。手机建议横屏；竖屏提示期间暂停游戏。

灯坊背景根据用户参考片中的画面重新生成，属于重绘背景，并非从原网站取得的原始摄影素材。前景灯笼和操作控件由本网页实时生成。来源说明见 `THIRD_PARTY_NOTICES.md`。

## 验证

开发服务运行后，需要 Python Playwright 与 `/usr/bin/chromium`：

```sh
python3 tests/journey_smoke.py
python3 tests/revision_smoke.py
python3 tests/medicine_smoke.py
python3 tests/offline_smoke.py
```

`journey_smoke.py` 覆盖真实开场按钮和翻页、叠化接入采药、实际掷骰、灯坊旋转、表面绘画、清除/纹样工具、自定义题字、点灯、图片下载、音乐非零音频采样与音频上下文连续性、退出重进及横屏触控。结果在 `/tmp/chuwen-journey-validation/`。

其余检查保留原作采药、医治、两轮拖药煎煮和单文件离线能力验证。自动化触屏与云端 Chromium 不能替代实体手机、Safari 和实际音响的体验复核。

## 重建下载包

```sh
python3 tools/build_offline.py
python3 tools/package_web.py
```

离线构建内嵌所有本地运行库、应用脚本、样式和图片。源码包只包含本版网页、素材、运行库和开发检查，不包含参考视频或旧版展示影片。旧版展示影片及其观看页未重剪，仍保存在 `showcase/`，不属于新版游戏离线包。

药名、配方与民俗情节只服务于互动叙事，不作现实用药建议。
