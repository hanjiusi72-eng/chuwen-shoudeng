# 光亮 · 龙虎灯（交互游戏网页）

原名《除瘟守灯》，现以「光亮」为主题——一盏龙虎灯，守一村灯火与人。横屏 H5 游戏，Phaser 3 实现，支持鼠标与触屏，程序化古风背景音乐（WebAudio 合成，无需音频素材）。美术素材取自 `跨媒体2 .ai` 的各个图层，采药棋盘与药庐济世界面参考《龙虎灯 · 灯与人》网页版素材。

## 运行

- **双击 `start.command`**：自动在本机开静态服务器并打开浏览器。
- 或在本目录执行 `python3 -m http.server 8686`，打开 <http://127.0.0.1:8686/>。
- 不要直接双击 `index.html`（file:// 下浏览器会拦截 WebGL 贴图）。
- 标题页底部「章节跳转（调试入口）」可直接进入任一交互，便于分段展示。

## 字体与音乐

- 全部文字使用黑体（Heiti SC / STHeiti / SimHei / Noto Sans SC 回退链）。
- 背景音乐由 `js/core.js` 的 `BGM` 引擎实时合成：宫调五声筝句 + 鼓点 + 木鱼 + 铜锣 + 长笛；守灯夜切换为低回的羽调「night」模式。右下角 🔊 可同时静音音效与音乐。

## 目录

```
index.html          入口（竖屏提示；js 链接带 ?v= 版本号防缓存）
js/core.js          全局状态、对白、按钮、提示、音效、BGM
js/data.js          药材、药方、摊位、吉语、守灯参数、幕间文案、采药棋盘配置
js/scenes/*.js      各场景（forage.js 为掷骰采药棋盘，medicine.js 含药庐济世界面）
assets/             从 AI 导出的素材；assets/v2/ 为棋盘与药庐素材
lib/phaser.min.js   Phaser 3.80（本地，无需联网）
```

所有药方只用于游戏判定，不作现实用药建议。
