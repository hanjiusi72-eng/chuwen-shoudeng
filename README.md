# 除瘟守灯 · 龙虎灯（交互游戏网页）

依据《PRD-除瘟守灯 v0.4》制作的横屏 H5 游戏，Phaser 3 实现，支持鼠标与触屏。美术素材全部取自 `跨媒体2 .ai` 的各个图层。

## 运行

- **双击 `start.command`**：自动在本机开静态服务器并打开浏览器。
- 或在本目录执行 `python3 -m http.server 8686`，打开 <http://127.0.0.1:8686/>。
- 不要直接双击 `index.html`（file:// 下浏览器会拦截 WebGL 贴图）。
- 标题页底部「章节跳转（调试入口）」可直接进入任一交互，便于分段展示。

## 流程（对应 PRD 第 3 节）

四个交互前各有「第一幕～第四幕」幕间界面（品红底纹 + 带网点分身的人物立绘 + 诗句 + 青色幕名，按设计稿制作），点击继续或 9 秒后自动进入。

| 节点 | 内容 |
| --- | --- |
| 序章 | 保生大帝吴夲，药房来了白额虎与青龙 |
| 交互 1A 治虎 | 点开药书（全程只需一次）→ 循环翻页找方 → 拖药入罐、选中变灰、配满自动判定 → 药葫芦拖给老虎 → 取出发簪 |
| 交互 1B 医龙 | 另一张药方 → 成药拖给青龙 → 龙首拉近，依次点两只龙眼 |
| 剧情 A | 龙虎入村、交付药书与采购线索、赠素灯 |
| 交互 2A 市集 | 6 个摊位，4 条提示无序完成；选错由龙虎解释并重复线索 |
| 交互 2B 功效制药 | 三种功效药顺序不限，成药自动入架；配错 / 已备好均有提示 |
| 剧情 B | 救治木匠，木匠邀请学扎灯 |
| 交互 2C 木匠家 | 扎骨架（圈架 + 竖骨）→ 糊灯面 → 装灯芯 → 添灯油，错件回弹 |
| 剧情 C | 全村制灯、服药、亮灯，入夜瘟神来袭 |
| 交互 3 守灯 | 60 秒；只能拖灯体移动的引路灯；沿固定路径吹灯的疫鬼；长按 2 秒救灯（黄色内填）与 10 秒彻底熄灭（红色外框）；随机鼓点（敲击才出声浪）；瘟神重雾需拖龙雨净化后再长按；教学可跳过；全灭只重试本夜，连续失败两次开辅助模式 |
| 剧情 D | 天明 |
| 交互 4 画灯 | 沿龙纹、虎纹轮廓描画（采样点计进度，80% 自动补全，可清除当前纹样）→ 三选一吉语可替换 → 完成 |
| 结尾 | 你的灯近景 → 全村挂灯 → 送王船（非交互）→ 完成页（重看结尾 / 重新体验） |

## AI 图层 → 游戏素材

| AI 图层（原默认隐藏的已逐一打开） | 用途 |
| --- | --- |
| 人物 | 青龙、白额虎、木匠 / 摊主（蓝衣人物）；同一人物着暗色剪影作瘟神 |
| 保生大帝 | 序章与结尾的吴夲 |
| 制药 | 竹简药书、竹简卷（合上的药书）、药炉、蒲扇、药臼、药房背景 |
| 采药 | 12 张药材卡（薄荷、麦冬、人参、茯苓、紫苏、连翘、半夏、金银花、陈皮、甘草、菊花、藿香）；龙首纹、虎首纹两张卡用作交互 4 的描画纹样 |
| 抓鬼（亮灯 / 灭灯） | 村庄地图，守灯与剧情背景（另合成了一张夜景版） |
| 序幕底纹 | 标题、幕间、剧情、画灯背景 |
| 骰子 | 杂货摊货物 |
| 图层 9～12（新增） | 带网点分身的龙 / 虎 / 木匠全身立绘 → 幕间界面；「第一幕」文字样式参考 |
| 瘟神 / 疫鬼 | 无设计稿，按原稿画风（几何脸 + 三角纹 + 格纹镶边 + 细金描边 + 网点分身）用脚本绘制：`wenshen.png`（大瘟神，持蒲扇）、`ghost.png`（小疫鬼），生成脚本在旧版 /tmp 已删，参数可改 `draw_ghosts.py` |

AI 文件里药材卡的文字因字体缺失在 PDF 层是乱码，名称已从 AI 私有数据中还原。药书中「藿香正气散、麦门冬汤、银翘散」来自设计稿（稿中「麦门东汤」按常用名写作「麦门冬汤」）；「舒喉化骨汤」「菊花明目饮」为治虎、医龙补的游戏药方。所有药方只用于游戏判定，不作现实用药建议。药方、摊位、守灯参数都集中在 `js/data.js`，方便调整。

## 目录

```
index.html          入口（含竖屏「请横屏体验」提示；js 链接带 ?v= 版本号防缓存）
js/core.js          全局状态、对白、按钮、提示、中文换行、合成音效
js/data.js          药材、药方、功效任务、摊位、吉语、守灯参数、幕间文案
js/scenes/*.js      各场景（act.js 为幕间界面）
assets/             从 AI 导出的素材
lib/phaser.min.js   Phaser 3.80（本地，无需联网）
```
