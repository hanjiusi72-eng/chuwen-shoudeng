# 长明 · 一盏灯，照见人间

一段关于药香、邻里与灯火的闽南民俗互动故事。保留原作几何纹样和高饱和民俗配色，以更有人情味的对白串联采药、医治龙虎、赶集、煎药、扎灯、守夜与画灯。

## 运行

项目为本地自包含的静态网页，无 npm 依赖，无账号或 API Key。

```sh
cd /workspace/chuwen-shoudeng
python3 -m http.server 8686
```

在运行服务器的设备上用浏览器访问对应端口。macOS 也可双击 `start.command`。请通过 HTTP/HTTPS 打开，勿直接使用 file://。横屏支持鼠标及触屏，竖屏时提示旋转并暂停游戏。

部署时将 `index.html`、`js/`、`lib/` 和 `assets/` 放在同一目录。所有链接使用相对路径，支持 GitHub Pages 仓库子路径。不依赖 CDN。

## 本次调整

- 主题更名为「长明」，重写序章、龙虎对白、入村、陈伯家、制灯与结尾，围绕“有人记得你，有人等你回家”。
- 统一使用随项目加载的黑体 `Changming Hei`（Noto Sans CJK SC 的字形子集，SIL OFL 许可见 `assets/FONT-LICENSE.txt`），不依赖用户设备是否安装黑体。
- 医治龙虎之前加入掷骰采药。十五格蛇形山路包含起点、十二味药材和龙虎节点；每次随机掷 1–6 点，路过的草药都入篓，终点截停，不会因运气缺药。走到终点后点击「回药房」。连续点击不会叠加行动。
- 制药页取消三张症状任务卡；改为竹简药书、药炉、圆形草药柜与成药展示。点击三种药名可直接查方，完成后显示已备好。治虎、医龙页也不再用症状栏介绍人物。
- 陈伯救治镜头只出现站立的木匠，不再出现龙虎、倒地、旋转起身或病症卡；该段对白也不显示龙虎头像。
- 加入 80 秒原创民俗配乐：108 BPM、D 大调五声音阶、合成笛声、拨弦、笙感和声与锣鼓。首次点击后播放，跨场景连续，右下角可关闭声音；切到后台自动暂停。
- 保留原有鼠标/触屏拖药、取簪、点眼、扎灯、长按续灯、驱雾、画纹与吉语选择。

流程：药房来客 → 第一幕 → **掷骰采药** → 治虎 → 医龙 → 入村 → 市集 → 三炉药 → **站立陈伯** → 扎灯 → 全村亮灯 → 守夜 → 画灯 → 尾声。

标题页「重访故事 · 选择篇章」可以分章体验。篇章入口会建立该章节所需的前置状态，适合展示；完整体验从「走进灯火」开始。

## 验证与演示制作

现有环境需要 Python、Playwright 和 `/usr/bin/chromium`。先启动静态服务器，再运行：

```sh
python3 tests/browser_smoke.py
```

测试覆盖采药流程、重复点击、错误药方恢复、龙虎医治、三炉药、木匠立姿、制灯、长按续灯、画灯题字、音乐及移动端横竖屏。测试结果与截图写到 `deliverables/validation/`。

云端浏览器的完整交互测试和录制采用 Phaser 自动支持的 Canvas 渲染模式，网页本身仍用 `Phaser.AUTO`，正常浏览器优先 WebGL。守夜测试验证了真实长按续灯，没有穷举随机胜负路径。

```sh
python3 scripts/record_demo.py
python3 scripts/make_film.py
```

先录制真实网页，再剪成 80 秒、1920×1080、30 fps 的 demo，包含片头、七段交互镜头、幕间、片尾及原创配乐。网页实录用篇章入口对应的场景状态做分段展示；守夜的熄灯状态使用游戏原有熄灯规则布置，续灯动作由真实长按完成。没有把静态示意图冒充网页操作。

`record_demo.py` 复用系统 FFmpeg，为 Playwright 在 `.cache/` 中建立本地路径。`compose_music.py` 可重新合成原创配乐（需要 NumPy、SciPy 和 FFmpeg）。`subset_font.py` 在新增文字后更新字体子集（需要 fontTools 和系统 Noto Sans CJK SC 字体）。

## 文件与素材

- `js/data.js`：药材、游戏配方、幕间、采购线索与守夜参数。
- `js/scenes/gather.js`：新增采药棋盘。
- `js/scenes/story.js`：对白、陈伯立姿及剧情分镜。
- `js/scenes/medicine.js`：药书、药炉、草药柜与医治交互。
- `assets/changming-festival.mp3`：网页背景音乐，原创程序合成，无外部录音采样。
- `deliverables/长明_电影感交互Demo.mp4`：独立 demo 视频（生成后提供，不随 Git 源码提交）。

美术沿用原仓库从《跨媒体2 .ai》导出的素材，Phaser 为原仓库自带本地运行库。新增字体许可随附。附录：`THIRD_PARTY_NOTICES.md`。

游戏中的药名、配方与民俗情节仅服务于故事与玩法，不作现实用药建议。现场真实手机的声音听感与触摸手感建议在目标设备再体验。
