# 长明 · 本次修改

主题定为「长明」，副题「一盏灯，照见人间」。用“看得见彼此”“一炉暖”“有人等你回家”贯穿故事，既有民俗灯火的寓意，也把救助写成邻里之间的照应。

## 附件对应

1. 木匠：救治段只保留陈伯一个人物。出场、停留和下一镜始终站立，不再倾倒、旋转或从病倒状态起身；该段也取消龙虎头像。保留木匠邀请你扎灯的故事衔接。
2. 制药界面：移除“缓解发热 / 缓解咳嗽 / 止呕消胀”三张症状任务卡。参考附件中的粉色药房、竹简药书、药炉和草药陈列重排，点药名可查方，药做好后收入展示架。
3. 掷骰采药：放在第一幕后、治虎和医龙之前。五列三行、十五格蛇形路线，用原有药材、人物和骰子素材。每次随机 1–6 点，经过的草药都会采到，不用反复碰运气；走到终点再回药房。
4. 字体：标题、对白、按钮及提示统一为黑体，字体文件随网页保存，无需依赖电脑已安装字体。
5. 声音：首次点击后播放古风民俗感的原创背景音乐，右下角可关闭；切到后台自动暂停。没有使用需要另行授权的商业歌曲。

## 文案节选

- 序章：“白礁的清晨，总有一缕药香先醒来……谁敲门，他都应一声‘来了’。”
- 青龙复明：“窗外那片青山，还有你们的笑脸……原来看得见彼此，是这样好的事。”
- 陈伯：“你送我一炉暖，我也教你扎一盏灯。”
- 守夜：“你护灯，青龙拨开雾，我来敲鼓……咱们就找得到彼此。”
- 结尾：“原来长明的，不只是一盏灯。是有人记得你，有人等你回家。”
